# Godot Souls-like Hitbox Logic
A small project focusing on the physics of combat in Godot 4. 

## What's in here?
- **Scythe Physics:** Using `Area2D` and `CollisionShape2D` for the swing.
- **Hitbox/Hurtbox setup:** Dedicated nodes for detecting when a player attack overlaps with an enemy.
- **State Logic:** Basic player states for swinging and movement.

## Why I made this
I wanted to figure out how to make combat feel snappy without relying on simple distance checks. This setup uses Godot's collision layers to handle everything.
