# Artwork Classifier (Pixel vs. Hand-drawn)
A quick prototype to see if a simple CNN can tell the difference between digital pixel art and scanned/hand-drawn sketches. 

## Why?
I do urban sketching and digital art. I wanted to see if I could build a model that understands the difference between the "blocky" nature of pixels and the pressure-sensitive strokes of a physical pen.

## Tech
- **Python / Keras**
- **Jupyter Notebook** (The main logic is in `.ipynb`)

## Status
- **It’s a prototype.** The model isn't 100% accurate yet; it struggles with "hybrid" styles where digital brushes mimic traditional ink.
- Currently working on expanding the dataset to include more edge cases.

## How to use
Just run the `classifier.ipynb` in Jupyter or Colab. You'll need `tensorflow` and `matplotlib` installed.
